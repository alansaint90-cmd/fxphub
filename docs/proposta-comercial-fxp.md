# Proposta comercial FXP

O template oficial para geracao de propostas e `proposta-comercial-fxp`.

Referencia visual salva no projeto:

`public/assets/proposta-comercial-fxp-reference.png`

Ao gerar uma proposta, o sistema deve usar essa referencia como base visual e comercial. A proposta nao deve ser criada do zero.

Pode alterar:

- Nome da empresa
- Logo da empresa
- Segmento
- Textos comerciais
- Imagens e recortes do site
- Links
- WhatsApp
- Instagram
- Google Maps
- Valores
- Prazo
- Validade da proposta

Deve preservar:

- Estrutura das secoes
- Estilo visual
- Paleta de cores
- Tipografia
- Espacamentos
- Cards
- Faixa animada
- Menu
- Botao flutuante do WhatsApp
- Bloco de investimento
- FAQ
- CTA final
